# 文件操作与恢复

## 删除流程

预检空间 → 复制整组到本地回收目录 → 比较大小与 CRC32 → 校验通过后删除源文件 → 追加 manifest。
源文件删除失败时保留副本并记录 partial 状态。它不提供整个文件组的数据库事务或断电原子性。

## 平铺回收目录

同名冲突使用 `_1`、`_2` 等序号。manifest 中 `files[].name` 记录实际副本名，
`files[].src` 保存原路径，`trash_root` 指定回收目录。恢复时使用原路径还原名称。
旧嵌套布局记录仍有兼容处理。追加式 JSONL 方便保留操作记录，但不是独立备份。

## 彻底删除与导出

彻底删除逐文件执行，不能递归删除平铺回收根目录。取消标记只匹配原名或 `_n` 序号副本。
迁移或更新前关闭程序，保留照片和 manifest 的独立备份。先用副本测试新版本，再处理原始 SD 卡。
