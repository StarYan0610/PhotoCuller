# 快捷键

| 按键 | 操作 |
| --- | --- |
| ← / →、滚轮 | 上一张 / 下一张 |
| Ctrl + 滚轮 | 以光标为中心缩放 |
| 双击、左键拖动 | 适应窗口与 100% 切换、放大后平移 |
| Delete / Ctrl+Z | 整组移入回收目录 / 会话内撤销 |
| Space / 鼠标中键 | 标记保留或取消标记 |
| M / Ctrl+Enter | 切换反选模式 / 批量移走未标记组 |
| Ctrl+E | 导出筛选结果 |
| Ctrl+T | 打开回收站 |
| Ctrl+C、O、Ctrl+O | 复制图片、默认程序打开、选择打开方式 |

日期多选内部取“或”，评分多选内部取“或”，日期与评分条件之间取“与”。空集合表示不筛选。
