# PhotoCuller

面向 Windows 的本地照片筛选工具。以同名文件为一组，浏览 JPG 时同步管理 CR3、HIF 等配套文件，让筛片、标记导出和恢复集中在一个窗口中完成。

Python · PySide6 · Pillow · 本地文件处理

## 功能

- 同名 JPG / JPEG / CR3 / HIF / HEIF 分组；无 JPG 的 RAW 组单独排尾。
- JPG 缩放预览、EXIF 自动旋转、缓存和后台预取；RAW 参与文件管理，不进行解码。
- 整组移入本地回收目录：先复制，再比较大小和 CRC32，验证通过后删除源文件。
- 会话内撤销、跨会话恢复、重名文件自动编号；回收站使用追加式 manifest。
- 日期与相机星级多选筛选，标记保留、反选批量处理、指定导出目录。

## 使用流程

1. 选择照片目录，检查分组和 JPG 预览。
2. 用方向键或滚轮浏览；Delete 整组移入回收目录，Ctrl+Z 撤销。
3. Space / 中键标记保留；可指定导出目录，按日期和评分筛选。
4. 在回收站管理窗口查看历史、恢复或手动彻底删除。

默认回收目录为 `桌面/PhotoCuller/回收站`。配置保存在 `%APPDATA%/PhotoCuller/config.json`。
首次使用请先用照片副本验证流程；CRC32 校验不替代独立备份。
